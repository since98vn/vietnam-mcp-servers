# Contributing

Thank you for helping keep the data right.

This repository contains documentation, client configs and examples. The servers themselves run on since98.vn, and their code is not published here, so we do not accept pull requests with code changes.

## Report a data error

Use **Issues → New issue → Data error**. A good report has:

1. **Which server and tool or endpoint**, for example `address / convert_old_to_new` or `GET /api/v1/payroll/gross-to-net`.
2. **What you sent** (please leave out personal data: no real names, phone numbers or full home addresses).
3. **What you got** and **what is right**.
4. **The official source**: the resolution, decree or Zalo page, with a link.

We check every report against the official source. When it is confirmed, we fix the data, release a new data version and note it in the issue.

## Suggest an improvement

Use **Issues → New issue → Feature request**: what you want to do, and for whom. New tools and fields are welcome ideas.

## Fixes to the documentation

Typos and unclear wording in this README or the examples: open an issue with the **Feature request** template and quote the text. Small documentation pull requests are also fine.

## Larger volumes or an integration

Need more than the free limit, bulk processing of a database, or these tools inside your own system? Write to hello@since98.vn or use https://since98.vn/contact.
